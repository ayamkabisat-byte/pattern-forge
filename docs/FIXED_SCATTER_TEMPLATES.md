# Fixed Scattered Placeholder Templates

The **Scattered** workspace now uses fixed, hand-authored seamless layouts instead of procedural scatter generation.

## Workflow
1. Choose one of the fixed templates.
2. Upload one or more SVG motifs.
3. Use **Placeholder Mapping** to choose which SVG fills every numbered slot.
4. Check **Master Tile** and **3×3 Proof**.
5. Export the seamless SVG/PNG or the blank numbered placeholder guide.

## Templates
- Scattered Cards
- Round Pebble Scatter
- Directional Tile Toss
- Oval Flow
- Large + Small Pebbles
- Diamond Pebble Layout
- Botanical Flow
- Quiet + Busy Scatter

Slots have fixed coordinates, sizes and rotations. Motifs near an edge automatically receive the matching wrapped copy on the opposite edge. There is no random placement or collision solver in this workflow.

The layouts are original PatternForge templates informed by the general placeholder-template workflow shown in the user's visual references; they do not copy a third-party template file.

# PatternForge v1.9

- Restores the best Legacy multi-SVG builder workflow as a lazy-loaded Multi-Motif Builder under Seamless.
- Adds Repeat Layout Tile Set mode for combining multiple complete square SVG pattern tiles into seamless super-tiles.
- Adds cycle-safe advanced Luxury Geometry controls and lattice presets.
- Hardens Tile Set deletion by remapping Custom Matrix indices and random weights without changing unaffected tile identities.
- Hardens Composer JSON import by reparsing/sanitizing embedded SVG assets and remapping placements to fresh asset IDs before rendering.
- Plaid/Tartan, Scarf/Hijab, Camouflage, Directional and Pixel engines are not modified by this release.

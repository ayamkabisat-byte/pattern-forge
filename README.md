# PatternForge

Browser-based seamless vector pattern generator.

PatternForge is designed for local, client-side SVG pattern creation with generic repeat systems and Indonesian-inspired pattern construction modes.

> Status: early MVP / v0.1 foundation.

## Goals

- Native SVG workflow
- True seamless master tile
- Live repeat preview
- Generic repeat systems: Grid, Half Drop, Brick, Toss
- Batik-oriented construction modes: Ceplok, Kawung-inspired, and later Lereng, Nitik, Isen-Isen, Tumpal
- Export SVG and PNG
- Keep uploaded artwork on the user's device whenever possible

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

The project is designed to deploy directly to Vercel from GitHub.
